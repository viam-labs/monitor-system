# monitor-system

A Viam Application that displays camera streams from a machine and its remotes.

Based on [`viam-labs/viam-camera-viewer`](https://github.com/viam-labs/viam-camera-viewer) by Naomi.

## Run locally

```bash
npm install
npm start
```

Opens on [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
```

Outputs to `build/`.
